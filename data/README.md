# Datos

Los directorios `raw`, `staging`, `processed` y `external` reservan las etapas del pipeline ETL.

- `raw/`: archivos originales recibidos, sin modificación.
- `staging/`: archivos inspeccionados antes de la transformación.
- `processed/`: datos normalizados listos para análisis.
- `external/`: datos procedentes de fuentes externas cuando estén autorizados.

La primera etapa no incluye datasets reales. Ningún dato mostrado en la interfaz debe interpretarse como información oficial.
